let's make a new gossamer command, gossamer handoff. At a high level, what i want to do is be able to transfer a session from one repo to another so that another agent can take it and resume it. If push_sessions is true in the config, this command shouldn't do anything, since entire already syncs the local checkpoints branch with the remote. However, if push_sessions is false: 1. if the session isn't on the latest git commit, call entire attach <sessionId>. 2. find the commit on the entire/checkpoints/v1 branch corresponding to this session. 3. use git push to push that specific checkpoint to the remote's entire/checkpoints/v1 branch. That way, other people/agents using gossamer will be able to access that session without having to publish all of their session history.
